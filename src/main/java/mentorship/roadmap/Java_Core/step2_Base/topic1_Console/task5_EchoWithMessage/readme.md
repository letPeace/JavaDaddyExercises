# Задача "Простое приветствие из консоли"

## Описание

Напишите Java-программу, которая:

- Считывает строку с консоли.
- Выводит её обратно с добавленным сообщением, например:  
  `Вы ввели: <введённый_текст>. Спасибо!`

## Требования

- Класс должен называться `EchoWithMessage`.
- Файл: `EchoWithMessage.java`.
