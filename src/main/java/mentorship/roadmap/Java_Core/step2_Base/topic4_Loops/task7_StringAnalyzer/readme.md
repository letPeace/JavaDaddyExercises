# Задача "Анализ строки"

## Описание

Напишите Java-программу, которая:

- Считывает строку с консоли.
- Разбивает её на символы или слова.
- Подсчитывает, сколько в строке:
    - Цифр
    - Букв
    - Пробелов
    - Прочих символов
- Выводит результаты.

## Требования

- Класс должен называться `StringAnalyzer`.
- Файл: `StringAnalyzer.java`.
