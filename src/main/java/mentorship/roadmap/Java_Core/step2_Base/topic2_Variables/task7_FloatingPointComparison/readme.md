# Задача "Сравнение чисел с плавающей точкой"

## Описание

Напишите Java-программу, которая:

- Объявляет две переменные `double` с близкими значениями.
- Сравнивает их напрямую через `==`.
- Сравнивает их с помощью `Math.abs(a - b) < EPSILON`.
- Выводит оба результата.

## Требования

- Класс должен называться `FloatingPointComparison`.
- Файл: `FloatingPointComparison.java`.
