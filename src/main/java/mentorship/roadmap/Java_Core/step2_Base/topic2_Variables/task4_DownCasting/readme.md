# Задача "Преобразование примитивов"

## Описание

Напишите Java-программу, которая:

- Объявляет переменную `double` с дробным значением.
- Явно преобразует её в `int`.
- Сравнивает полученное значение с оригиналом.
- Выводит оба значения.

## Требования

- Класс должен называться `DownCasting`.
- Файл: `DownCasting.java`.
