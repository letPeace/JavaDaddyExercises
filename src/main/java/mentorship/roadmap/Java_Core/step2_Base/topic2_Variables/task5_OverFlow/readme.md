# Задача "Переполнение переменных"

## Описание

Напишите Java-программу, которая:

- Объявляет переменную `byte` со значением 127.
- Прибавляет к ней 1 и сохраняет результат в новую переменную.
- Выводит оба значения.

## Требования

- Класс должен называться `OverflowDemo`.
- Файл: `OverflowDemo.java`.
