# Задача "Логические сравнения переменных"

## Описание

Напишите Java-программу, которая:

- Объявляет две переменные `int` с разными значениями.
- Сравнивает их (больше/меньше/равно).
- Результат сохраняет в переменные типа `boolean`.
- Выводит все логические результаты.

## Требования

- Класс должен называться `VariableComparison`.
- Файл: `VariableComparison.java`.
