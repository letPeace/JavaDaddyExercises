# Задача "Проверка, отсортирован ли массив"

## Описание

Напишите Java-программу, которая:

- Создаёт массив целых чисел.
- Проверяет, отсортирован ли он по возрастанию.
- Выводит `true`, если отсортирован, иначе `false`.

## Требования

- Класс должен называться `IsSortedAsc`.
- Файл: `IsSortedAsc.java`.
