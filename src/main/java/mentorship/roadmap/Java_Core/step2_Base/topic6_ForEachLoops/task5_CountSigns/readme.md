# Задача "Подсчёт положительных и отрицательных чисел"

## Описание

Напишите Java-программу, которая:

- Создаёт массив целых чисел.
- Подсчитывает количество положительных, отрицательных и нулей.
- Выводит результат.

## Требования

- Класс должен называться `CountSigns`.
- Файл: `CountSigns.java`.
