# Задача "Животное и Собака"

## Описание

Вам дан базовый класс `Animal`, в котором:

- Есть поле `name` (имя животного)
- Конструктор с параметром `name`
- Метод `makeSound()`, который ничего не делает

Создайте подкласс `Dog`, который:

- Добавляет поле `breed` (порода)
- Переопределяет метод `makeSound()` и выводит "Гав!"
- В конструкторе вызывает `super(name)` и инициализирует `breed`
- В `main()` создаёт объект `Dog` и вызывает `makeSound()`

## Требования

- Класс `Animal` в файле `Animal.java`
- Класс `Dog` в файле `Dog.java`
