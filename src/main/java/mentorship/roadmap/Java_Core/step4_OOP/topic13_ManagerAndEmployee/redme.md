# Задача "Сотрудник и Менеджер"

## Описание

Есть класс `Employee`, в котором:

- Поля: `name`, `salary`
- Конструктор с параметрами `name` и `salary`
- Статическая переменная `employeeCount` и метод `getCount()`
- Метод `getAnnualSalary()`, возвращающий годовую зарплату

Создайте класс `Manager`, который:

- Наследует `Employee`
- Добавляет поле `bonus`
- Переопределяет `getAnnualSalary()`: годовая + бонус
- Конструктор вызывает `super(name, salary)` и инициализирует `bonus`
- В `main()` создаёт двух `Manager` и печатает общее число сотрудников

## Требования

- `Employee.java` и `Manager.java`
