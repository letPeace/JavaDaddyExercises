# Задача "LinkedList как очередь"

## Описание

Напишите Java-программу, которая:

- Инициализирует `LinkedList<String>`.
- Использует его как очередь (FIFO):
    - добавляет элементы через `offer()`
    - извлекает через `poll()`
- Выводит каждый извлечённый элемент до тех пор, пока очередь не пуста.

## Требования

- Класс должен называться `QueueLinkedList`.
- Файл: `QueueLinkedList.java`.
