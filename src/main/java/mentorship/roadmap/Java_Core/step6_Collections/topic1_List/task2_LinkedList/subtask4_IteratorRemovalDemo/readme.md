# Задача "Удаление по условию с итератором"

## Описание

Напишите Java-программу, которая:

- Создаёт `LinkedList<Integer>` с числами от 1 до 10.
- Использует `Iterator` для удаления всех чётных чисел.
- Выводит финальный список.

## Требования

- Класс должен называться `IteratorRemovalDemo`.
- Файл: `IteratorRemovalDemo.java`.
