# Задача "Удаление по индексу и значению"

## Описание

Напишите Java-программу, которая:

- Создаёт список `ArrayList<String>`.
- Добавляет туда несколько строк.
- Удаляет элемент по индексу и по значению.
- Выводит результат после каждого удаления.

## Требования

- Класс должен называться `RemoveFromList`.
- Файл: `RemoveFromList.java`.
