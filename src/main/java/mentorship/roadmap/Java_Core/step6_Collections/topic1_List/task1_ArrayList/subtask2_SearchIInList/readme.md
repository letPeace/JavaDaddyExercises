# Задача "Список строк и поиск"

## Описание

Напишите Java-программу, которая:

- Создаёт `ArrayList<String>`.
- Добавляет туда несколько строк (например, имена).
- Запрашивает строку с консоли.
- Проверяет, содержится ли эта строка в списке.
- Выводит: `"Найдено"` или `"Не найдено"`.

## Требования

- Класс должен называться `SearchInList`.
- Файл: `SearchInList.java`.
