# Задача "Динамическое заполнение списка"

## Описание

Напишите Java-программу, которая:

- Создаёт `ArrayList<String>`.
- Читает строки с консоли, пока пользователь не введёт `"стоп"`.
- После этого выводит количество введённых строк и список.

## Требования

- Класс должен называться `DynamicInputList`.
- Файл: `DynamicInputList.java`.
