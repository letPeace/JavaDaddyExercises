# Задача "Объединение двух списков"

## Описание

Напишите Java-программу, которая:

- Создаёт два списка: `ArrayList<String> first` и `second`.
- Добавляет в них разные строки.
- Объединяет их в третий список.
- Выводит итоговый список на экран.

## Требования

- Класс должен называться `MergeLists`.
- Файл: `MergeLists.java`.
