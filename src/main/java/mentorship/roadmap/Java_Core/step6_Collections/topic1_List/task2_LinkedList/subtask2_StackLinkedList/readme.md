# Задача "LinkedList как стек"

## Описание

Напишите Java-программу, которая:

- Инициализирует `LinkedList<Integer>`.
- Использует его как стек (LIFO):
    - добавляет элементы через `push()`
    - удаляет через `pop()`
- Выводит каждый извлечённый элемент в консоль.

## Требования

- Класс должен называться `StackLinkedList`.
- Файл: `StackLinkedList.java`.
