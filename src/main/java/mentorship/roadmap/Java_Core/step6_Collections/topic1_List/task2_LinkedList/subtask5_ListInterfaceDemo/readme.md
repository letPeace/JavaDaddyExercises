# Задача "Обработка как List"

## Описание

Напишите Java-программу, которая:

- Объявляет переменную типа `List<String>` и инициализирует через `new LinkedList<>()`.
- Добавляет элементы через `add(index, element)`.
- Заменяет элемент по индексу через `set()`.
- Удаляет элемент через `remove(index)`.
- Выводит содержимое списка через `for` с индексами.

## Требования

- Класс должен называться `ListInterfaceDemo`.
- Файл: `ListInterfaceDemo.java`.
