# Задача "Сравнение производительности LinkedList и ArrayList"

## Описание

Напишите Java-программу, которая:

- Инициализирует `ArrayList<Integer>` и `LinkedList<Integer>`.
- Добавляет по 100_000 элементов в конец каждого списка.
- Измеряет время вставки в начало 10_000 элементов для каждого.
- Выводит затраченное время на обе операции.

## Требования

- Класс должен называться `PerformanceCompare`.
- Файл: `PerformanceCompare.java`.
