# Задача "Телефонный справочник"

## Описание

Создайте Java-программу, которая:

- Использует `HashMap<String, String>`, где ключ — имя человека, а значение — его номер телефона.
- Добавляет в справочник несколько записей.
- Позволяет пользователю ввести имя с консоли и получить соответствующий номер телефона.
- Если имя не найдено — выводит сообщение об этом.

## Требования

- Класс должен называться `PhoneBook`.
- Файл: `PhoneBook.java`.
