# Задача "Максимальное значение в HashMap"

## Описание

Создайте Java-программу, которая:

- Имеет `HashMap<String, Integer>`, где ключ — имя участника, значение — его баллы.
- Находит и выводит участника с наибольшим количеством баллов.

## Требования

- Класс должен называться `TopScorer`.
- Файл: `TopScorer.java`.
