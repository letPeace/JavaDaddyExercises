# Задача "Счётчик повторений с getOrDefault()"

## Описание

Создайте Java-программу, которая:

- Имеет массив слов: `{"dog", "cat", "dog", "bird", "cat", "dog"}`.
- Считает, сколько раз каждое слово встречается, используя `HashMap<String, Integer>` и метод `getOrDefault()`.
- Выводит результат: слово и его количество.

## Требования

- Класс должен называться `WordCounter`.
- Файл: `WordCounter.java`.
