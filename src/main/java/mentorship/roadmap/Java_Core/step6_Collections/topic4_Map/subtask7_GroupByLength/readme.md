# Задача "Группировка строк по длине"

## Описание

Создайте Java-программу, которая:

- Имеет массив строк: `{"hi", "hello", "hey", "hola", "yo", "bonjour"}`.
- Группирует строки по их длине, используя `HashMap<Integer, List<String>>` и метод `computeIfAbsent()`.
- Выводит: длина → список строк.

## Требования

- Класс должен называться `GroupByLength`.
- Файл: `GroupByLength.java`.
