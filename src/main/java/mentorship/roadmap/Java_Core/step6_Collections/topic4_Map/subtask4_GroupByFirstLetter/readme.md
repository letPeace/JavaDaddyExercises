# Задача "Группировка строк по первой букве"

## Описание

Создайте Java-программу, которая:

- Имеет массив строк (например, имена).
- Использует `HashMap<Character, List<String>>` для группировки строк по первой букве.
- Выводит результат: для каждой буквы — список соответствующих строк.

## Требования

- Класс должен называться `GroupByFirstLetter`.
- Файл: `GroupByFirstLetter.java`.
