# Задача "Преобразование и сортировка HashSet"

## Описание

Напишите Java-программу, которая:

- Создаёт `HashSet<Integer>` и заполняет его числами.
- Преобразует `HashSet` в `ArrayList`.
- Сортирует получившийся список.
- Выводит отсортированные элементы.

## Требования

- Класс должен называться `SetToListSort`.
- Файл: `SetToListSort.java`.
