# Задача "Диапазоны в TreeSet"

## Описание

Создайте Java-программу, которая:

- Инициализирует `TreeSet<Integer>` с числами от 1 до 20.
- Использует методы `headSet()`, `tailSet()` и `subSet()`:
    - Выводит все элементы **меньше 10**.
    - Выводит все элементы **от 10 и больше**.
    - Выводит элементы **от 5 до 15 (не включая 15)**.

## Требования

- Класс должен называться `TreeSetRanges`.
- Файл: `TreeSetRanges.java`.
