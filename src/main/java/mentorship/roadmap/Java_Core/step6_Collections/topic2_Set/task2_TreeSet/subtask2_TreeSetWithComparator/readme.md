# Задача "TreeSet с пользовательским порядком"

## Описание

Создайте Java-программу, которая:

- Инициализирует `TreeSet<String>` с лексикографическим порядком в **обратную сторону** (от Z к A).
- Добавляет строки (например, "Banana", "Apple", "Orange").
- Выводит элементы, чтобы показать, что они отсортированы по убыванию.

## Требования

- Класс должен называться `TreeSetWithComparator`.
- Файл: `TreeSetWithComparator.java`.
