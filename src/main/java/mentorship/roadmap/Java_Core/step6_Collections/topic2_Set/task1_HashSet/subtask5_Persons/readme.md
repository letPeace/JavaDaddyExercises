# Задача "HashSet с собственными объектами"

## Описание

Напишите Java-программу, которая:

- Создаёт класс `Person` с полями `name` и `age`.
- Переопределяет `equals()` и `hashCode()` на основе обоих полей.
- Создаёт `HashSet<Person>` и добавляет туда нескольких людей, включая дубликаты по `name` и `age`.
- Выводит только уникальные объекты.

## Требования

- Классы: `Person.java`, `UniquePersons.java`.
