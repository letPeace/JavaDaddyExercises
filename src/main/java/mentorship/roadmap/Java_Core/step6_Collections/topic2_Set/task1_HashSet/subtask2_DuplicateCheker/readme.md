# Задача "Проверка дубликатов"

## Описание

Напишите Java-программу, которая:

- Читает с консоли несколько строк (пока не будет введено "стоп").
- Сохраняет строки в `HashSet<String>`.
- Если строка уже была введена, выводит сообщение `"Дубликат!"`.
- В конце печатает все уникальные строки.

## Требования

- Класс должен называться `DuplicateChecker`.
- Файл: `DuplicateChecker.java`.
