# Задача "TreeSet с объектами и Comparable"

## Описание

Создайте Java-программу, которая:

- Объявляет класс `Book` с полями `title` и `year`.
- Реализует интерфейс `Comparable<Book>`, сравнивая книги по году.
- Добавляет несколько книг в `TreeSet<Book>`.
- Выводит отсортированные по году книги на экран.

## Требования

- Классы: `Book.java`, `BookSetDemo.java`.
