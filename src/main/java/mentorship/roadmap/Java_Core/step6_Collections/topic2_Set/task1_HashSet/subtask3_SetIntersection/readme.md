# Задача "Общие элементы двух HashSet"

## Описание

Напишите Java-программу, которая:

- Создаёт два `HashSet<String>`, с разными значениями (например, имена).
- Находит и выводит все элементы, которые встречаются в обоих множествах.

## Требования

- Класс должен называться `SetIntersection`.
- Файл: `SetIntersection.java`.
